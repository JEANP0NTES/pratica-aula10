# Changelog

Todas as mudanças notáveis deste projeto serão documentadas neste arquivo, seguindo o [Versionamento Semântico](https://semver.org/).

## [2.0.0] - 2026-11-20
### Alterado (Quebra de compatibilidade)
- Removida a função antiga `calcular_taxa_legado()` da API pública.
- Atualizado o formato de retorno das consultas para JSON estruturado.

## [1.1.0] - 2026-11-15
### Adicionado
- Adicionado suporte para exportação de relatórios em formato CSV.
- Incluído filtro de busca por data no painel principal.

## [1.0.1] - 2026-11-10
### Corrigido
- Corrigido erro de arredondamento no cálculo de valores decimais.
- Resolvida falha na validação de campos vazios no formulário de login.
